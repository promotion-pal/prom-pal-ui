# Prom Pal UI 📦

Кастомная, легковесная и адаптивная библиотека компонентов форм на базе **React**, **TypeScript**, **React Hook Form** и **Tailwind CSS**.

Разработана для быстрой инициализации и переиспользования проверенной логики форм (маски, паттерны, валидация) между различными проектами.

---

## 🚀 Способ 1: Использование в стиле shadcn/ui (Рекомендуемый)

Если вы хотите скопировать чистый исходный код компонентов прямо в свой проект, чтобы иметь возможность свободно редактировать верстку и стили «на месте».

### 1. Выгрузка компонентов в проект
Запустите команду в терминале вашего основного проекта, указав целевую папку (например, `src/features/lib/form`):

```bash
npx degit promotion-pal/prom-pal-ui/form src/features/lib/form --force
```

### 2. Установка необходимых зависимостей
Поскольку код переносится напрямую, убедитесь, что в вашем основном проекте установлены базовые библиотеки:

```bash
pnpm add react-hook-form lucide-react clsx tailwind-merge
```

### 3. Использование в коде
Импортируйте компоненты локально из папки, куда вы их скачали:
```tsx
import { PromFieldInput } from "@/features/lib/form/text/prom.form.input";
import { PromForm } from "@/features/lib/form/prom.form";
```

## 📦 Способ 2: Установка как npm-пакета (Закрытая библиотека)

Если вам нужно использовать компоненты «как есть», без изменения их внутреннего кода в целевом проекте. Все обновления будут управляться централизованно через этот репозиторий.

### 1. Установка из GitHub
Выполните команду в корне вашего основного проекта:

```bash
pnpm install git+https://github.com
```

### 2. Обновление до свежей версии
Если вы внесли правки в этом репозитории и запушили их в `main`, обновите пакет в целевом проекте одной командой:

```bash
pnpm update prom-pal-ui
```

### 3. Использование в коде
```tsx
import { PromForm, PromFieldInput } from "prom-pal-ui";
```

## 🛠️ Разработка и структура библиотеки

Если вы хотите добавить новый компонент формы или изменить логику, делайте это **внутри этого репозитория**, а не в `node_modules` рабочих проектов.

```text
form/
├── date/          # Компоненты для выбора даты
├── select/        # Кастомные селекты и выпадающие списки
├── text/          # Текстовые инпуты, пароли, маски (PromFieldInput)
├── types/         # Общие TypeScript типы и интерфейсы
├── utils.ts       # Утилита `cn` для объединения классов Tailwind
└── index.ts       # Главный файл экспорта (входная точка)
```

### Правила добавления новых компонентов:
1. **Адаптивность:** Не задавайте компонентам фиксированную ширину в пикселях (например, `width: 350px`). Всегда используйте `w-full` (100%), чтобы компонент подстраивался под родительский контейнер (Grid/Flexbox) на целевом сайте.
2. **Экспорт:** После создания нового компонента обязательно добавьте строку экспорта в корневой файл `form/index.ts`:
   ```typescript
   export * from "./text/my-new-input";
   ```
3. **Пуш изменений:** После редактирования отправьте код на GitHub:
   ```bash
   git add .
   git commit -m "feat: добавил новый тип инпута"
   git push
   ```
